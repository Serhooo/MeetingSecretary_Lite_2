# Руководство: ИИ-Секретарь Lite 2

## 1. Перенос и запуск

Скопируйте папку `MeetingSecretary_Lite_2` целиком на Windows-компьютер и запустите `Запустить_секретаря.bat`. Для запуска используются portable Python из `runtime`; устанавливать Python отдельно не нужно.

Для автономной работы оставьте рядом с приложением папки `runtime`, `models` и `whisper-cache`. В кэш включены веса Whisper small и файлы GigaAM-v3 ONNX. Проверьте комплект через `Проверить_среду.bat`.

В заголовке окна показываются обнаруженные характеристики компьютера: модель процессора, объём оперативной памяти и версия Windows.

## 2. Модели

### Распознавание речи

В списке ASR доступны Whisper tiny, small, medium, large-v3-turbo и GigaAM-v3 E2E RNNT. **Whisper small** выбран по умолчанию как баланс качества русского распознавания и скорости на CPU.

1. Выберите модель в списке `ASR`.
2. Нажмите `⬆ ASR`.
3. Дождитесь сообщения, что распознавание готово.
4. Начните запись или импортируйте существующий аудиофайл.
5. После завершения распознавания при необходимости нажмите `⏏ ASR`, чтобы освободить память.

В комплект включён кэш Whisper small и GigaAM-v3. Whisper tiny, medium и large-v3-turbo загружаются в `whisper-cache` при первом выборе и требуют интернета, если их веса ещё не скачаны. Перенесите этот кэш вместе с приложением для автономного использования.

### Протокол и проверка стенограммы

В комплекте выбрана локальная модель `Gemma-4-E2B-Uncensored-HauhauCS-Aggressive-Q6_K_P.gguf`.

1. Нажмите `⬆ LLM` перед проверкой текста, созданием протокола или анализом Mind Map. Допускается запустить соответствующее действие сразу — приложение предложит загрузить LLM.
2. Проверьте результат LLM: генерация может ошибаться, особенно в именах, терминах, суммах, сроках и решениях.
3. Нажмите `⏏ LLM`, когда обработка завершена и память нужна для других задач.

ASR и LLM загружаются и выгружаются независимо. Для распознавания аудио LLM не требуется. Gemma занимает несколько гигабайт оперативной памяти; скорость зависит от CPU, объёма RAM и длины контекста.

Выбор `API` остаётся доступен как дополнительный вариант. В этом режиме стенограмма отправляется выбранному серверу. Для публичных адресов обязателен HTTPS; HTTP разрешён для localhost и частных IP локальной сети (`10.x.x.x`, `172.16–31.x.x`, `192.168.x.x`, IPv6 ULA). Для LM Studio укажите базовый URL сервера, например `http://10.97.120.204:1234`; приложение автоматически отправит запрос на OpenAI-совместимый маршрут `/v1/chat/completions`. Можно также явно указать базовый адрес с `/v1`. Имя модели в поле `Модель` должно совпадать с API Model Identifier в LM Studio, например `qwen/qwen3.5-9b`. HTTP не шифрует стенограмму и API-ключ: используйте его только в доверенной локальной сети; для недоверенных сетей настройте HTTPS. Ключ хранится в Windows Credential Manager.

## 3. Источники звука

Доступны два источника:

- `Микрофон Windows по умолчанию` — системное устройство ввода по умолчанию;
- `Системный звук Windows` — запись loopback с устройства вывода Windows по умолчанию.

Loopback захватывает общий звук, который Windows воспроизводит через устройство вывода, а не звук конкретного приложения. Если системный звук не появляется, запустите `Проверить_среду.bat`; для loopback требуется PyAudioWPatch, указанный в `requirements-audio.txt`.

Настройка чувствительности меняет программный порог обнаружения речи. Она не меняет уровень аппаратного усиления. При высокой чувствительности может распознаваться больше фонового шума.

Перед встречей можно включить `Сохранять аудио`. Программа предложит путь и сохранит выбранный источник в WAV mono/16 kHz.

## 4. Работа со стенограммой

Во время записи текст добавляется в область стенограммы. После записи можно исправить его вручную, запустить проверку LLM и сравнить предложенный вариант с исходником. Подтверждайте исправления только после проверки: LLM не может надёжно восстановить неразборчивую речь без аудио.

Словарь терминов в Lite удалён. GigaAM backend не использует пользовательские лексические подсказки; контекстная замена или исправление текста словарём не производится.

Параметры сегментации доступны по паузам, длительности, смысловым фразам и смене спикера. Точность диаризации зависит от чистоты аудио; одновременная речь остаётся сложным случаем. Профили голосов можно редактировать и переносить кнопкой `Профили`.

В поле `Спикеры` можно выбрать:

- `По профилям` — использовать сохранённые голосовые профили;
- `Автоматическая` — определять разные голоса в текущей встрече без профилей;
- `Отключена · быстрый текст` — пропустить вычисление голосовых эмбеддингов и получать распознанный текст по ходу встречи. По умолчанию программа накапливает не менее 3 секунд звука на фрагмент, чтобы реже разрывать предложения; значение `с фрагмент` можно увеличить для ещё более длинных частей и меньшей частоты разделения, с соответствующим ростом задержки. Распознанные части дописываются в один непрерывный текст без меток времени и имён спикеров. Кнопка `⏸ Пауза` приостанавливает захват и дожидается распознавания уже собранного звука, а `▶ Продолжить` добавляет одну метку времени паузы и продолжает текст после неё. При нажатии `⏹ Стоп` обрабатывается последний остаток. Это пакетное распознавание коротких блоков, не потоковые токены; фактическая задержка зависит от выбранной модели и скорости компьютера.

При выключенной диаризации имя по одному содержанию речи определить нельзя. В быстром режиме спикеры не подписываются; повестка не назначает говорящих и не меняет стенограмму. При создании протокола LLM получает повестку для группировки тем, но не должна приписывать имя только потому, что человек говорил на соответствующую тему.

Кнопка `🗂 Повестка` открывает редактор, где можно ввести темы и докладчиков вручную или загрузить TXT, Markdown и Word DOCX. Текущая повестка и библиотека часто используемых тем сохраняются в `meeting_agenda.json` рядом с программой; перенесите этот файл вместе с Lite 2 для сохранения данных. Повестка передаётся LLM для проверки стенограммы, протокола и Mind Map. Библиотека помогает повторно использовать контекст, но не обучает и не дообучает LLM. Повестка не служит подтверждением принятых решений.

Кнопка `Очистить стенограмму` удаляет текущую стенограмму, протокол и статистику после подтверждения. Сохранённые профили спикеров при этом сохраняются.

## 5. Ограничения и рекомендации

- GigaAM-v3 E2E RNNT в этой интеграции выдаёт текст фрагмента без подробных таймкодов слов; диаризация внутри фрагмента может быть менее точной, чем на Whisper.
- Проверьте стенограмму и протокол перед передачей или использованием как официального документа.
- Если компьютеру не хватает памяти, выгрузите LLM во время распознавания. После распознавания её можно загрузить для генерации протокола.
- Выходная скорость зависит от компьютера и квантизации Gemma; Q6 даёт более крупные веса, чем Q4-квантизация.
